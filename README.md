# Dragon Pets Simulator

Jeu Roblox de collection de dragons : farm d'or, œufs, combats contre des dragons sauvages, apprivoisement, évolution bébé → ado → adulte.

- `docs/Dragon_Pets_GDD.docx` : document de conception du jeu (règles, chiffres, mondes, dragons, économie, organisation technique).
- `modeles_3d/` : modèles 3D des dragons (Blender) et scripts de génération. Voir `modeles_3d/README.md`.
- `mcp_config.json` : configuration MCP pour Roblox Studio.
